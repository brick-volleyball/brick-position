左上ラベルを編集

設定

S=セッター / OH=アウトサイドヒッター / MB=ミドルブロッカー / OP=オポジット / L=リベロ
個別に枠線色を指定したメンバーは、メンバー設定側の色が優先されます。
モードを切り替えるとコート上の配置はリセットされます(名簿は消えません)。
6分割・9分割は配置モード(6人制/9人制/制限なし)に関わらず、いつでも選べます。
保存先フォルダは未設定です。未設定の場合は保存のたびにダウンロードされます。
対応環境(Android Chrome / PC Chrome等)では、一度選択したフォルダを次回以降も記憶します。iPhone Safari等、File System Access APIに非対応の環境では、常にダウンロードフォルダへの保存になります。
